# 港股 AKShare 三表币种独立复核

核查日：2026-11-10。结论范围为 `stock_financial_hk_report_em` 的金额样本，不能扩展成“所有 AKShare 港股接口都返回人民币”或“所有港股公司都用人民币列报”。

本次把接口原始数值作为待验证对象，验证依据使用发行人原始财报与中国人民银行汇率公告；不以东方财富自己的页面标注作为独立证明。没有调用模型、妙想付费工具或交易接口。

用十进制定点数检验 `接口金额 − 官方原币金额 × 同日原币兑人民币中间价`，五项残差全部为0。三种原始列报币种的样本一致支持：这条接口的这些货币金额为人民币基本单位，已发生供应商折算；并不是港币金额，也不是始终保留发行人原币。

该比值与期末中间价完全一致是本轮观测结果，不是所有报告期换算算法的无限保证。不能据此用当前汇率重算过去数据，也不能把这种供应商折算表称为公司按人民币编制的财报。EPS、股数、百分比仍按各自字段定义，不因本次货币金额核查而统一改单位。

## 来源独立性

实际读取的本地 AKShare 源码文件为 `akshare/stock/finance/stock_finance_hk_em.py`；`stock_financial_hk_report_em` 请求地址就是 `datacenter.eastmoney.com`，三表使用 `RPT_HKF10_FN_*_PC`。因此它确实是东方财富封装，不能用 AKShare 与东方财富互相当成独立来源。

本次只用该接口返回数字作样本，用公司官方报表、央行官方公告交叉核验。若要求数据采集链也完全不经过东方财富，这个函数无法满足要求，需要改用已接入的港交所官方披露及另行验证的结构化源。本轮没有将“不能同源自证”解释成自动改变整套数据渠道政策。
