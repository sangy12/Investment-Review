# 已采纳的免费补充源接入

2026-11-10 已在 `config/redteam.yaml` 启用，原有节点、辩论轮数与模型配置保持不变。没有注册新账户、注入新 key 或连接交易接口。新代码不重写此前已完成报告；下一次新运行使用本配置即可取得新增材料。

## 路由和材料

- 美国宏观：`macro_data: fred_public,fred`。当前日期先走官方 FRED 公开下载，失败或未验证系列才回退原 FRED API。A/H 为 `akshare,fred_public,fred`；只有明确 `china_*` 才送中国宏观接口，裸 `cpi`、`gdp` 与美国利率不替换为中国值。
- FRED 当前白名单为 CPI、核心 CPI、失业率、2/10 年美债、联邦基金利率、PCE/核心 PCE 的指定系列。每个系列按分析日锁定缓存一次；HTTP 超时 20 秒、压缩响应上限 4 MiB、解压总量上限 8 MiB，不提取 ZIP 到文件系统。校验日期、数字和系列列，过滤请求窗口之外的数据，最多显示最近 40 个有效观察值。
- 三市场预测：美股 Yahoo EPS/营收预测，A 股 AKShare/同花顺 EPS/净利润预测，港股 AKShare/经济通综合预测。第三方 SDK 在数据层独立子进程中执行，总超时 45 秒，最多保留每表 8 行；只有年份/机构数却没有预测值的行不算预测数据。
- 港股社区：富途公开 `stock_feed`，每标的请求最多 30 条，保留最近七个上海日内、不晚于抓取时刻、关联标的且有实质文本的样本；去重、去 HTML，最多保留最新 5 条，每条正文最多 600 字符。非富途链接不保留，富途链接去查询参数。没有在抓取阶段制造看多比例，互动量未取到则为 UNKNOWN。
- 预测与社区进入现有共享材料包，各代理共用，成功报告沿用现有 JSON/Markdown/HTML 归档。新增材料也受上下文上限约束，省略数量明确记录；完整材料包另行保存。

## 缓存和时点约束

`research_sources.consensus_snapshots` 与 `research_sources.futu_community` 为显式开关，未开启的其他 profile 不自动查询。预测与社区按“标的 + 分析日 + 材料类型”缓存，失败也缓存，避免每位代理重复请求。港股社区默认仅对 HK 市场启用。

历史日期在请求前拒绝公开 FRED 当前修订快照、盈利预测和实时社区；FRED 历史需求可继续走原 API 的 vintage 路径，但仍需要 key。断点恢复沿用原来捕获的材料和完整配置签名，不混入今天的新快照。新增开关改变配置签名，旧配置断点不得强行拼接。

抓取时间不是预测形成时间；观察期不是宏观发布日期。保留每表的财年/期间、币种、原始单位、分析师数、均值与范围等实际字段，未给出的口径和形成日期维持 UNKNOWN。FRED 数值说明当前修订状态，CPI/PCE 指数水平不等于通胀百分比。社区是有限样本的公开意见，不代表整个市场或公司披露。
