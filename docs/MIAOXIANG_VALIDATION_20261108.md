## 原文证据

公告返回的茅台三季报及半年报，与此前从巨潮下载的 PDF **SHA-256 完全一致**。这说明找到的是相同披露文件，并不意味着两家独立数据源。

- [茅台三季报](https://pdf.dfcfw.com/pdf/H2_AN202610301831245500_1.pdf)：可核对人民币元财报与人民币万元经营拆分，累计期间清楚。
- [茅台半年报](https://pdf.dfcfw.com/pdf/H2_AN202608141827994408_1.pdf)：可核对产品/销售渠道和精确财务数值。
- [腾讯中期报告中文版](https://pdf.dfcfw.com/pdf/H2_AN202608251828410860_1.PDF)、[第二季业绩公布](https://pdf.dfcfw.com/pdf/H2_AN202608121827904541_1.PDF)、[第一季业绩公布](https://pdf.dfcfw.com/pdf/H2_AN202605131822268712_1.PDF)：已确认 PDF 中发行人为腾讯，可回溯报表币种、自由现金流和资本开支定义，以及回购与员工激励购股的区分。

发行人的财务指标、Choice 聚合指标与公司事件是不同口径。例如：

- 腾讯工具返回“企业自由现金流量 FCFF”，不能直接改名为公司在业绩公告中定义的自由现金流。
- 回购工具返回日期、数量、平均价，不能当作报告期回购现金支付，更不能自动满足“排除员工激励购股”的条件。
- 腾讯原文将回购现金支付与员工激励购股分别列示。当前结构化问题没有可靠返回这个拆分，需要回到 PDF。
- 茅台经营表含“其他项目”和合计，收入占比的分母必须与原文对应；不得把使用不同分母的比例直接用于同一经营结论。

原始响应、PDF 和提取文本均保存在 Git 排除的 `reports/validation/`。验收 JSON 只保留公开元数据、字段问题、查询文字及文件指纹，不含密钥和 MCP 会话 ID。

## 在项目中的定位

建议保留妙想作为可选补充源：

1. 以公告检索定位发行人 PDF，验证主体、发布时间与原文；按公告编号/文件指纹缓存，避免对同份报告反复付费检索。
2. 使用 A 股产品、渠道及港股分部数据作为经营结构线索；原字段、期间、币种、显示精度和分母都保留，并回到原文核对。
3. 港股通用财务汇总、FCF、资本开支、回购暂逐项验收。当前自然语言查询无法稳定约束原币和期间，不直接放进自动财务归一化流程。

基础行情与已验证财报适配器继续保留。历史 as-filed 版本、全字段覆盖、无人值守续期和长期积分成本均未在本轮全部验收。完整红队报告还需 ChatGPT 订阅登录成功后执行。
