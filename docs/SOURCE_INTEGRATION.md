## 运行与缓存

红队批处理先校验订阅及模型访问，再准备每标的一份共享材料，注入既有 instrument context，各代理共用。代理本身不能发起妙想付费调用。初始化和节点顺序保持原样。

妙想按“标的 + 最近两期财报日期 + 材料类型”锁定缓存，每个新报告期组合最多两次工具调用（公告一次、经营结构一次），失败结果也缓存，避免断线重跑反复计费。无法识别当前报告期或没有密钥时不发付费请求。报告期发现由 AKShare 子进程完成，45 秒超时后使用已有材料并注明缺口。

这不等于每日付费监控全部临时公告：同报告期的新事项先由公开资讯提供线索，需要重新检索时显式刷新。`--skip-unchanged` 仍是输入去重，不判断远端是否有更新。

富途公开资讯按分析日缓存；原文 PDF 按公开 URL 建立缓存并记录 SHA-256。仅下载固定披露域名的无查询参数 PDF，每份最多 8 MiB、每次最多 3 个新文档；不跟随跳转。若有 `pdftotext`，另外记录索引片段是否在 PDF 文本中匹配，但不把它当作全部数值/发行主体已经核验。

历史日期在任何网络/缓存读取前拒绝这些当前快照，保留原有财报历史保护，不声称具有历史 as-filed 数据。

```bash
# 默认仅看缓存：不登录模型、不调用妙想、不新增积分消耗
bash scripts/cloud.sh sources --only 0700.HK
bash scripts/cloud.sh sources --only 600519.SS

# 主动发现报告期并按需取新材料（可能消耗积分）
bash scripts/cloud.sh sources --only 0700.HK --no-cached-only

# 显式重新检索相同报告期或重试失败查询（最多两次付费调用）
bash scripts/cloud.sh sources --only 0700.HK --no-cached-only --refresh
```

每次成功报告保留 `research_sources.json`、`research_sources.md`，合并 Markdown/HTML 均带来源材料；快照记录显示材料指纹。补充源失败只留下明确缺口，不改变原有主链，也不推断“没有风险”。
